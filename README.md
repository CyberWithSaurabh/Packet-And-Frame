# Packet and Frames – TryHackMe Lab

## 📌 Lab Overview

The **Packet and Frames** room on TryHackMe introduces the fundamentals of how data travels across a network.
It explains the difference between packets and frames and how information is encapsulated as 
it moves through the layers of the OSI model.

This lab helps learners understand how network communication works and builds a strong foundation for network analysis and cybersecurity monitoring.

Packet and Frames
Packet and Frames is a TryHackMe room focused on teaching foundational networking concepts within a cybersecurity context.
It explains how data travels across networks by breaking it into packets and frames, and helps learners understand 
analysis tools such as Wireshark. The room is designed for beginners exploring network traffic, encapsulation,
and protocol behavior.


Key facts
Platform: TryHackMe

Difficulty: Easy

Focus: Networking fundamentals and packet/frame structure

Tools used: Wireshark, terminal utilities (ping, traceroute)

Learning path: Part of the Pre Security and Network Fundamentals tracks

Networking fundamentals
The room introduces the concept of packets (Layer 3, Network layer units) and frames (Layer 2, 
Data Link layer units) using interactive labs and visual examples. Learners analyze how 
data is encapsulated as it moves through the OSI model, showing differences between 
IP packets and Ethernet frames.


Hands-on learning
Exercises guide users through capturing and examining network traffic with Wireshark. Scenarios include identifying MAC and IP addresses, 
inspecting headers, and following data flow between devices. These tasks help solidify theoretical knowledge with real-world packet inspection experience.

Educational relevance
Understanding packets and frames is foundational for anyone studying networking or cybersecurity. The room builds key skills for network analysis, intrusion detection,
and troubleshooting. It supports progression to more advanced TryHackMe rooms covering protocols like TCP, UDP, and ICMP.
